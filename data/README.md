# Data

**DataCo Smart Supply Chain for Big Data Analysis** (public)
Constante, F., Silva, F. and Pereira, A. (2019). Mendeley Data, V5. doi:10.17632/8gx2fvg2k6.5
Also on Kaggle as "DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS".

Download `DataCoSupplyChainDataset.csv` (about 96 MB) into this folder. It is not stored in this repository
because of its size and because it contains customer names and emails. `python/load.py` keeps only the
24 business columns and drops all personal data.

`monthly_extract_2017-09.csv` and `monthly_extract_2017-08.csv` are small sample extracts (order lines only, no
personal data) for testing the Excel report.
